# Security policy

Please report suspected security vulnerabilities privately to [hello@papat.app](mailto:hello@papat.app). Do not report them in public GitHub Issues. Include the affected CLI version, macOS version, and steps to reproduce when possible. Do not include API keys, passcodes, gallery URLs, client names, or photos.

For bugs and feature requests, use GitHub Issues. For usage questions, account matters, and billing, email [hello@papat.app](mailto:hello@papat.app). This project is operated by one person, so reports are handled in order; no response time is promised.
